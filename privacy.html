Calha privacy policy

Last updated 31 October 2026.

What it accesses. With the owner's permission, Calha reads calendar events from the owner's Google account so they can be shown on the owner's Home Assistant server.

Where data goes. Calendar data is stored only on the owner's Home Assistant server at home. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Google API data. Calha's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be revoked at any time at myaccount.google.com/permissions.

Contact. Through the owner's GitHub profile, github.com/dboulay89-glitch.
